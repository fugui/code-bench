## 📑 核心技术文档导读

### 1. [01-子系统微前端插件化开发接入指南.md](./01-子系统微前端插件化开发接入指南.md)
* **面向读者**：架构师、微前端集成工程师。
* **核心内容**：CodeBench 运行时动态加载机制、数据交互时序、网关反向代理与权限体系全景说明。

### 2. `02-业务模块模板工程文档/`（推荐新模块研发优先阅读 ⭐）
* **面向读者**：基于 `code-template` 自研扩展业务功能模块的研发团队。
* **核心内容**：
  * **3 分钟起步**：使用 `scripts/init-module.sh` 一键派生新模块并挂载至 CodeBench。
  * **全栈规范实战**：Go 后端表名前缀隔离、JWT/RBAC、操作审计 Diff、隔离测试库；React 前端 `@code/common` 组件矩阵与亮/暗双模 Design Tokens 规范。
  * **交付与排错**：单二进制 `go:embed` 打包、端口分配建议、上线前 15 项必过自检表与高频排障手册。
